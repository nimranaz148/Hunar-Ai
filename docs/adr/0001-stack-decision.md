# ADR 0001: Technology Stack Decision for Hunar v2

- **Status:** Accepted
- **Date:** 2026-09-26 (Updated 2026-09-29)
- **Decider:** Nimra (Product Owner & Solo Developer)

## Context

Hunar v2 is an AI-powered platform for Pakistani home-business women, featuring an automated business intake and planning flow, a 30-day multi-agent content calendar engine, a mentor marketplace with simulated payments, and program cohort management.
The development timeline targets a contest delivery on 10 Oct 2026, built by a solo developer on a free-tier and open-source budget.

## Decision

We adopt **Preset A** (Python + TypeScript monorepo with production profile):

1. **Frontend:** Next.js 15 (App Router, TypeScript strict mode) + Tailwind CSS v4 + shadcn/ui.
   - Hosted on **Vercel** (Hobby free tier).
2. **Backend:** FastAPI + SQLAlchemy 2 (async) + Pydantic v2.
   - Hosted on **FastAPI Cloud** (official managed hosting by Tiangolo, deployed via `uv run fastapi deploy`).
3. **Database:** PostgreSQL 16 hosted on **Supabase** (free tier), with migrations managed by **Alembic**.
4. **API Contract:** OpenAPI 3.1 auto-generated by FastAPI, generating a TypeScript client in `packages/api-client` with CI drift enforcement.
5. **AI Agents:** OpenAI Agents SDK with **Google Gemini 2.5 Flash** as LLM provider via OpenAI compatibility endpoint. Web search via **Tavily API**.
6. **Tracing & Observability:** Custom `DbTraceProcessor` storing spans in Postgres `agent_steps` table.
7. **Scoping & Security:** Custom JWT (short-lived access + rotating httpOnly refresh tokens) with 3 roles (`entrepreneur`, `mentor`, `super_admin`) and append-only `audit_logs`.

## Consequences

### Positive
- Zero recurring hosting costs during development and contest demo.
- Clean separation between Next.js UI, FastAPI business logic, and OpenAI Agents SDK pipeline.
- Single command deployment to FastAPI Cloud and Vercel.
- Mechanical quality enforcement through `scripts/verify.sh` covering python, alembic, web, contract, and infra lanes.

### Negative / Trade-offs
- Free tiers have rate limits (Gemini 15 RPM, Tavily 1,000 queries/month, Supabase 500MB DB).
- No Redis/Celery; background agent runs are tracked in Postgres with async tasks and semaphores.
- Real payment processing and WhatsApp/Meta auto-posting are deferred.
